# Elpis Property Limited — Demonstration Guide

Use only Elpis staging resources and clearly labelled fictional test data. Do not import or reuse Bliss demo accounts, passwords, client records, properties, payment references or documents.

Demonstration sequence:
1. Open the Elpis staging website.
2. Register a test client using a controlled test email address.
3. Sign in using the Elpis test staff accounts created specifically for this environment.
4. Demonstrate role-based dashboards and branch permissions.
5. Create a clearly labelled test property and client allocation.
6. Demonstrate payment test flows only after the Elpis ALATPay test configuration is confirmed.
7. Review reports, commissions, notifications and audit activity.
8. Remove test data using the documented safe test-data procedure before production launch.

Never use production payment credentials or real customer personal information in demonstrations.
